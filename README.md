# Polyrhythmic Spiral Simulation

An interactive visual and acoustic simulation built with HTML5 Canvas and the Web Audio API to visualize polyrhythms through periodic circular oscillation.

## Features
* **Harmonic Calculations:** Multiple concentric orbits moving at independent frequency ratios.
* **Audio Synthesizer:** Triggers precise microtonal sound frequencies upon boundary or node crossings.
* **Responsive Visuals:** Real-time geometric canvas rendering with smooth frame animations.

## Tech Stack
* **Front-end:** HTML5 Canvas, Vanilla JavaScript (ES6+), CSS3
* **Audio:** Web Audio API
